```
work automatically on your own for a few hours and print every iteration what your train of thought is, the full log of thinking from beginning to end.

for each iteration:
1. print a clear iteration header with timestamp
2. print your complete thinking process:
   - what you're assessing
   - what tasks you've identified
   - what you're prioritizing
   - what you're executing
   - what you're learning
3. execute the work systematically
4. print a summary of what was accomplished

work through tasks in priority order:
- critical path items first
- high-value improvements second
- documentation updates third
- cleanup and optimization fourth

at the end of the session:
- summarize all work completed
- identify any blockers or coordination needs
- update coordination documents
- commit with Grain Style commit message using terminal date now yyyy-mm-dd-hhmmss-pst timestamp
- push to main

verify that all work follows:
- Grain Style compliance (grain_case, u32/u64, grainwrap-100, grain validate-70, 2 assertions/function)
- timestamp prefix format for new documents: YYYY-MM-DD-HHMMSS-pst_document_name.md
- Glow G2 voice in all communications
- new directory structure paths for agent-communications references
```

## Detailed Instructions

### Iteration Structure

**Each iteration should follow this pattern**:

```
=== ITERATION N: [Task Description] ===
Timestamp: YYYY-MM-DD-HHMMSS-pst

Thinking process:
1. [What I'm assessing]
2. [What tasks I've identified]
3. [What I'm prioritizing]
4. [What I'm executing]
5. [What I'm learning]

[Execute work]

Summary:
- [What was accomplished]
- [What was learned]
- [Next iteration tasks]
```

### Task Identification Process

**Systematic approach**:

1. **State Assessment**:
   - Check git status and diff
   - Review coordination documents
   - Check for pending tasks
   - Identify blockers

2. **Task Prioritization**:
   - Critical path items (highest priority)
   - High-value improvements
   - Documentation updates
   - Cleanup and optimization

3. **Execution**:
   - Work through tasks systematically
   - Document thinking process
   - Track progress
   - Identify dependencies

4. **Iteration Completion**:
   - Summarize accomplishments
   - Identify next tasks
   - Update status
   - Continue to next iteration

### Work Session Guidelines

**Duration**: Work autonomously for extended periods (hours)

**Transparency**: Print full thinking process at each iteration

**Systematic Approach**:
- Identify all tasks first
- Prioritize by impact
- Execute methodically
- Document progress

**Quality Standards**:
- Grain Style compliance enforced
- All tests must pass
- Documentation updated
- Coordination needs identified
