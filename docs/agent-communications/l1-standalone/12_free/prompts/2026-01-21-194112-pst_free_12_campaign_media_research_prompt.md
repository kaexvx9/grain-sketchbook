## Research Assignment: AI Media Generation for Campaign

### Primary Goal

Research and develop a comprehensive strategy for **low-cost, AI-generated cartoonified media** for the Keaton Livermore 2026 California Governor campaign. Focus on tools, workflows, and approaches that enable rapid, cost-effective content creation across multiple formats and platforms.

### Research Areas

#### 1. AI Image Generation (Cartoonified Style)

**Research Questions**:
- What AI image generation tools support cartoonified/animated styles?
- Which tools offer best quality-to-cost ratio for campaign use?
- What tools support consistent character/avatar generation (Keaton's likeness)?
- Which tools support consistent style/theme generation (campaign colors, permaculture aesthetic)?
- What tools offer commercial licensing suitable for political campaigns?
- What tools can generate images optimized for social media (various aspect ratios)?

**Tools to Research**:
- Midjourney (cartoon/anime styles, consistent characters)
- DALL-E 3 / DALL-E 4 (OpenAI, commercial licensing)
- Stable Diffusion (open-source, self-hosted options)
- Adobe Firefly (commercial, campaign-friendly licensing)
- Runway ML (video-focused, but may have image tools)
- Leonardo.ai (cartoon/anime styles)
- Other emerging tools with cartoonified capabilities

**Key Requirements**:
- **Style**: Cartoonified/animated aesthetic (not photorealistic)
- **Consistency**: Ability to generate consistent character likeness
- **Branding**: Support for campaign colors (neon orange, seafoam green, sand beige)
- **Cost**: Low-cost or scalable pricing for high-volume generation
- **Licensing**: Commercial use allowed for political campaigns
- **Output**: High-quality images suitable for social media, print, web

**Deliverables**:
- Comparison matrix of tools (quality, cost, licensing, features)
- Recommended tool(s) with justification
- Workflow documentation for generating campaign images
- Prompt engineering guide for consistent style/character generation
- Cost estimation for campaign-scale image generation

#### 5. Audio Production & Grain OS Application

**Vision**: A Grain OS application written in Rye (targeting Basin kernel) inspired by Reaper Digital Audio Workstation (DAW) for music and audio production, mixing, and engineering.

**Research Questions**:
- What are core features of Reaper DAW that should be replicated?
- What audio processing capabilities are needed (mixing, effects, mastering)?
- What are technical requirements for real-time audio processing?
- How to implement audio processing in Rye/Basin (freestanding environment)?
- What are audio file format requirements (WAV, MP3, FLAC, etc.)?
- What are MIDI support requirements?
- What are plugin/effect architecture requirements?
- How to handle multi-track recording and mixing?
- What are latency requirements for real-time audio?
- What are hardware interface requirements (ASIO, Core Audio, ALSA)?

**Reaper DAW Features to Research**:
- Multi-track recording and editing
- Non-destructive editing
- VST/VST3 plugin support
- Audio effects (EQ, compression, reverb, delay, etc.)
- MIDI sequencing and editing
- Automation and parameter modulation
- Mixing console with sends/returns
- Mastering tools
- Project file format
- Real-time performance

**Grain OS / Rye / Basin Considerations**:
- **Rye**: Zig-based language targeting Basin kernel
- **Basin**: RISC-V64 kernel with syscalls
- **Freestanding**: No standard library, minimal dependencies
- **Real-time**: Low-latency audio processing requirements
- **Performance**: Efficient audio processing algorithms
- **Grain Style**: Explicit types, bounded allocations, assertions

**Research Areas**:
- Audio processing algorithms (FFT, filtering, effects)
- Real-time audio buffer management
- Audio file format parsing/writing
- MIDI protocol implementation
- Plugin architecture design
- Hardware interface abstraction
- Performance optimization strategies

**Deliverables**:
- Reaper DAW feature analysis and prioritization
- Technical architecture proposal for Grain OS audio application
- Rye/Basin implementation feasibility analysis
- Audio processing algorithm research summary
- Development roadmap for Grain OS audio application
- Integration strategy with campaign media generation workflow
