graincards are 103 characters wide by 80 lines tall
teaching cards designed for knowledge preservation and
sharing. each card is a complete unit of information,
optimized for portrait 8.5x11 inch paper printing.

format specifications:
- width: 103 characters (hard wrap, no overflow)
- height: 80 lines (content-only, no borders)
- aspect ratio: optimized for portrait paper
- content: all 103x80 characters are content
- borders: handled by printer software, not included

rationale for 103x80:
- 8.5 inch paper width at 8 pixels per character = 68
  characters per line (with margins)
- 11 inch paper height at 8 pixels per line = 88 lines
  (with margins)
- 103x80 provides optimal content density while
  maintaining readability
- portrait orientation matches standard paper format

## Project Context

**Grain OS Development Focus** (2026-01-03):

**Framework x86_64 Ubuntu Development** (One End of Spectrum):
- Native development and testing on Framework hardware (x86_64 AMD)
- JIT compilation from RISC-V to x86_64 for Framework Ubuntu deployment
- sevenos integration targeting Framework x86_64 hardware
- Legacy Intel x86_64 support for first-responder Dispatch software

**Toroidal RISC-V Hardware R&D** (Other End of Spectrum):
- Research and development of toroidal hardware architectures
- Capitalizing on RISC-V for high-performance computing and machine learning synthesis
- Silicon Torus HPC hardware design and research
- Toroidal ML synthesis framework development

**RISC-V as Unifying Architecture**:
- Framework x86 development: RISC-V kernel runs in VM, JIT compiles to x86_64
- Toroidal hardware R&D: Native RISC-V execution on custom hardware
- Both directions leverage RISC-V architecture for different deployment targets
- Basin Kernel (RISC-V) serves as the core kernel for both deployment paths

**Current Status**:
- Basin Kernel: RISC-V kernel with syscall interface, running in VM with JIT
- VM Runtime: RISC-V to ARM64 JIT complete, RISC-V to x86_64 JIT in progress
- sevenos: NixOS-based system integration, unified with Grain OS architecture
- Toroidal Research: Whitepapers complete, hardware-first R&D direction established
