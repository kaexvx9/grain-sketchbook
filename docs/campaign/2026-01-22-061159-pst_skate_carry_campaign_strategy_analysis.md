## Skate & Carry Campaign Applications

### Skate (Knowledge Graph) for Campaign

**What Skate Is**:
- Native macOS knowledge graph application with social threading
- Temporal queries, AI-powered insights, DAG integration
- Currently designed for macOS Tahoe 26.1 (Zig 0.15.2)

**Campaign Applications**:
1. **Campaign Content Knowledge Graph**:
   - Organize campaign messaging, policy positions, content
   - Connect vegan animal rights activism to other platform planks
   - Visualize relationships between issues, policies, messaging
   - AI-powered insights for messaging optimization

2. **Voter Engagement Knowledge Graph**:
   - Track voter interests, concerns, engagement patterns
   - Connect voters to relevant content, events, opportunities
   - Organize volunteer networks, supporter relationships
   - Social threading for campaign discussions

3. **Alternative to Big Social Media**:
   - Knowledge graph interface for campaign content
   - No toxic advertising, no algorithm manipulation
   - Community-controlled, privacy-respecting
   - Fair-trade infrastructure in action

**Timeline for Campaign**:
- **Month 1-2**: Get Skate working on macOS (basic knowledge graph)
- **Month 3-4**: Add campaign-specific features (content organization, voter engagement)
- **Month 5**: Launch campaign knowledge graph application
- **June Primary**: Voters using Skate for campaign content

### Carry (Mobile Framework) for Campaign

**What Carry Is**:
- Mobile framework infrastructure for Grain OS
- Native mobile applications (Android/iOS) with offline-first architecture
- FFI bindings for Zig-to-mobile integration
- Mobile UI patterns, touch-optimized interfaces

**Campaign Applications**:
1. **Campaign Mobile App (iOS/Android)**:
   - Voter engagement, event information, volunteer signup
   - Policy positions, messaging, content
   - Vegan animal rights activism content and resources
   - Offline-first for areas with poor connectivity

2. **Voter Organizing App**:
   - Volunteer coordination, canvassing tools
   - Event management, RSVP, check-in
   - Community organizing, supporter networks
   - Direct voter contact, no big tech intermediaries

3. **Alternative to Big Social Media**:
   - Mobile app for campaign content and engagement
   - No toxic advertising, no algorithm manipulation
   - Community-controlled, privacy-respecting
   - Fair-trade infrastructure in action

**Timeline for Campaign**:

- **Month 3-4**: Build campaign mobile app (voter engagement, content)
- **Month 5**: Launch campaign mobile app (iOS/Android)
- **June Primary**: Voters using mobile app for campaign engagement
