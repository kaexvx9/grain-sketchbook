# Content Management Strategy

**Date**: 2026-01-21  
**Status**: Strategy Phase

---

## Overview

Managing content across website and 8+ social platforms efficiently with volunteer/staff team.

## Content Sources

### Single Source of Truth

**Option 1: Git-based (Recommended for Technical Team)**
- Markdown files in `/content/` directory
- YAML frontmatter for metadata
- Version controlled, easy rollback
- Volunteers edit via GitHub/GitLab UI or pull requests

**Option 2: Headless CMS**
- Strapi, Contentful, or Sanity
- Non-technical volunteers can edit
- API-driven, flexible
- May add complexity/cost

**Option 3: Hybrid**
- Git for code/structure
- CMS for content updates
- Best of both worlds

## Social Media Management

### Platform Strategy

**Primary Platforms:**
- YouTube - Long-form video content
- TikTok - Short-form video content
- Twitter/X - Quick updates, engagement
- Threads - Conversations, community
- Instagram - Visual content, stories
- Facebook - Broad reach, events

**Emerging Platforms:**
- Bluesky - Decentralized alternative
- Nostr - Protocol-based, censorship-resistant

### Content Workflow

1. **Create Content** (Video, Image, Text)
2. **Post to Primary Platform** (YouTube, TikTok, etc.)
3. **Cross-post to Other Platforms** (Automated or manual)
4. **Link from Website** (Simple links, no embeds)

### Tools

**Content Creation:**
- Video editing: DaVinci Resolve (free), Premiere Pro
- Image editing: GIMP, Photoshop, Canva
- Graphics: Figma, Inkscape

**Scheduling/Posting:**
- Buffer - Multi-platform scheduling
- Hootsuite - Social media management
- Later - Visual content calendar
- Custom scripts - For Nostr/Bluesky

**Analytics:**
- Google Analytics - Website traffic
- Platform analytics - Native insights
- UTM parameters - Track link clicks

## Team Roles

### Content Creators
- Write blog posts
- Create graphics
- Film/edit videos
- Take photos

### Social Media Managers
- Schedule posts
- Engage with comments
- Monitor mentions
- Track analytics

### Website Maintainers
- Update content
- Fix bugs
- Monitor performance
- Deploy updates

### Volunteers
- Can help with any role
- Training provided
- Clear guidelines
- Recognition system

## Content Calendar

### Weekly Schedule
- Monday: Platform announcement
- Wednesday: Policy deep-dive
- Friday: Community highlight
- Weekend: Behind-the-scenes

### Content Types
- Video: 1-2 per week
- Blog post: 2-3 per week
- Social posts: Daily
- Graphics: As needed

## Automation

### What to Automate
✅ Cross-posting to multiple platforms  
✅ Link generation with UTM parameters  
✅ Image optimization  
✅ Performance monitoring  
✅ Backup/version control  

### What to Keep Manual
❌ Content creation  
❌ Community engagement  
❌ Strategic decisions  
❌ Crisis response  

## Budget Considerations

### Free Tools
- Git/GitHub - Version control
- GIMP - Image editing
- DaVinci Resolve - Video editing
- Buffer (free tier) - Limited scheduling

### Paid Tools (if budget allows)
- Buffer/Hootsuite Pro - Full scheduling
- Canva Pro - Advanced graphics
- Analytics tools - Better insights
- Hosting/CDN - Performance

### Volunteer Time
- Most valuable resource
- Clear roles and expectations
- Recognition and appreciation
- Training and support

## Success Metrics

- **Content Output**: Consistent posting schedule
- **Engagement**: Likes, shares, comments
- **Website Traffic**: Visitors from social links
- **Team Satisfaction**: Volunteers feel valued
- **Performance**: Site stays fast

## Recommendations

1. **Start Simple**: Git-based content, manual posting
2. **Scale Gradually**: Add tools as team grows
3. **Document Everything**: Clear guidelines for volunteers
4. **Monitor Performance**: Keep site fast, track metrics
5. **Stay Flexible**: Adapt as platforms change
