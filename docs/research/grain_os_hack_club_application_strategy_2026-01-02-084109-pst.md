## Executive Summary

This document evaluates Grain OS eligibility for Hack Club fiscal sponsorship and provides recommendations for fiscal sponsorship vs. independent 501(c)(3) vs. hybrid approach. Based on the analysis, **Grain OS should consider a hybrid approach**: independent 501(c)(3) foundation for core infrastructure, with potential fiscal sponsorship for specific projects (e.g., Dispatch software work).

**Key Findings**:
- **Eligibility**: Grain OS is adult-led, which limits direct eligibility for Hack Club Bank (primarily for teen-led projects), but exceptions exist (e.g., Ghostty)
- **Recommendation**: Pursue independent 501(c)(3) foundation for Grain OS core infrastructure, with fiscal sponsorship considered for specific mission-aligned projects
- **Application Strategy**: If pursuing fiscal sponsorship for specific projects, contact HCB directly to discuss eligibility and application process
- **Timeline**: Independent 501(c)(3) setup (3-9 months) vs. fiscal sponsorship (1-2 weeks)

## 2. Recommendation: Fiscal Sponsorship vs. Independent 501(c)(3) vs. Hybrid

### 2.1 Comparison Summary

Based on the comparison document (`docs/research/fiscal_sponsorship_vs_independent_501c3_comparison_2026-01-01-091849-pst.md`):

| Factor | Fiscal Sponsorship (HCB) | Independent 501(c)(3) |
|--------|-------------------------|----------------------|
| **Setup Time** | 1-2 weeks | 3-9 months |
| **Setup Cost** | $0 | $500-$6,000 |
| **Ongoing Cost** | 7% of revenue | 0% (self-managed) |
| **Autonomy** | Limited | Full |
| **Control** | Shared with sponsor | Full |
| **Eligibility** | Teen-led (with exceptions) | No restrictions |
| **Scalability** | Limited | High |

### 2.2 Recommendation: Hybrid Approach

**For Grain OS Core Infrastructure**: **Independent 501(c)(3) Foundation**

**Rationale**:
- **Full Autonomy**: Grain OS needs full control over governance and decision-making
- **Scalability**: Core infrastructure benefits from independent foundation structure
- **Long-term Sustainability**: Independent foundation provides stable, long-term structure
- **No Ongoing Fees**: Avoid 7% fiscal sponsorship fee on core infrastructure funding
- **Eligibility**: No eligibility restrictions for independent 501(c)(3)

**For Specific Projects**: **Fiscal Sponsorship (If Eligible)**

**Examples**:
- **Dispatch Software Work**: If seeking immediate tax-exempt status for first-responder systems work, fiscal sponsorship could provide immediate capability (1-2 weeks) while independent 501(c)(3) is being established
- **JG Project**: If seeking immediate tax-exempt status for community impact work, fiscal sponsorship could provide immediate capability

**Rationale**:
- **Immediate Tax-Exempt Status**: Fiscal sponsorship provides immediate capability (1-2 weeks) vs. independent 501(c)(3) (3-9 months)
- **Project-Specific**: Fiscal sponsorship can be project-specific, allowing core infrastructure to maintain independent structure
- **Lower Setup Cost**: $0 setup cost for fiscal sponsorship vs. $500-$6,000 for independent 501(c)(3)

### 2.3 Recommended Path Forward

**Phase 1: Establish Independent 501(c)(3) Foundation** (3-9 months)
- Incorporate at state level
- Apply for IRS tax-exempt status (Form 1023 or 1023-EZ)
- Establish governance structure and bylaws
- Set up financial management and compliance systems
- **Purpose**: Long-term structure for Grain OS core infrastructure

**Phase 2: Evaluate Fiscal Sponsorship for Specific Projects** (Parallel or Sequential)
- Contact Hack Club Bank to discuss eligibility for specific projects (e.g., Dispatch software work)
- Evaluate fiscal sponsorship for projects needing immediate tax-exempt status
- Consider fiscal sponsorship as interim solution while independent 501(c)(3) is being established
- **Purpose**: Immediate tax-exempt status for specific projects, if eligible

## 4. Implementation Timeline

### 4.1 Independent 501(c)(3) Foundation Timeline

**Phase 1: Incorporation** (1-4 weeks)
- Choose state for incorporation
- File articles of incorporation
- Obtain EIN (Employer Identification Number)
- Establish initial board of directors

**Phase 2: IRS Application** (2-9 months)
- Form 1023-EZ (if eligible): 2-6 months
- Form 1023 (full application): 3-9 months
- Respond to IRS questions and requests
- Receive determination letter

**Phase 3: Operations Setup** (1-2 weeks)
- Establish bylaws and policies
- Set up financial management systems
- Set up donation processing
- Begin operations

**Total Timeline**: 3-9 months

### 4.2 Fiscal Sponsorship Timeline (If Pursuing)

**Phase 1: Application** (1-2 days)
- Complete application form
- Submit application materials

**Phase 2: Onboarding** (1 week)
- Schedule and complete onboarding call
- Review fiscal sponsorship agreement

**Phase 3: Agreement** (1-2 days)
- Sign fiscal sponsorship agreement
- Set up financial tools

**Total Timeline**: 1-2 weeks

### 4.3 Recommended Sequencing

**Option 1: Independent 501(c)(3) First** (Recommended for Core Infrastructure)
- Start independent 501(c)(3) application process (3-9 months)
- Establish foundation structure
- Use fiscal sponsorship for specific projects if needed (1-2 weeks)

**Option 2: Fiscal Sponsorship First** (If Immediate Tax-Exempt Status Needed)
- Apply for fiscal sponsorship for specific project (1-2 weeks)
- Begin receiving tax-deductible donations immediately
- Start independent 501(c)(3) application process in parallel (3-9 months)
- Transition from fiscal sponsorship to independent 501(c)(3) when ready
