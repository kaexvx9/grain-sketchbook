**Recommended**:
- Parameter spaces with 10-100 parameters
- Periodic/bounded constraints

- Single-threaded deterministic execution
- Bounded allocation constraints

**Not Recommended**:

**Small Problems (n < 20)**:

- Computation time: < 50ms

- Memory: < 10KB

- Use diagonal approximation
