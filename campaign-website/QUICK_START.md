# Quick Start Guide

## 🚀 Get Running in 2 Minutes

```bash
# 1. Install dependencies (first time only)
npm install

# 2. Start development server
npm run dev

# 3. Open http://localhost:5173 in your browser
```

That's it! The site is now running locally.

## 📁 What's Included

- ✅ Full site structure with sections
- ✅ Color scheme (light/dark mode)
- ✅ All core components
- ✅ Performance optimizations
- ✅ Clear stubs for placeholder content

## 🔍 Finding Stubs

Look for orange **STUB** badges throughout the site - these mark placeholder content that needs to be filled in.

## 📚 Full Documentation

## 🐛 Issues?

- **npm not found**: Install Node.js from nodejs.org
- **Port in use**: Vite will use next available port
- **Module errors**: Run `npm install` again
